What the three positions did

At |λ|=2 the real direction's value-logit percentile was 92.4%, 92.4%, and 98.5% across the starting, early-game, and king-only positions. The association-layer percentiles were 71.2%, 89.4%, and 98.5%. The endgame position also reached the 92.4th percentile for policy-logit sensitivity.

In the starting position, +2 changed the winning value bin from 43 to 37 while leaving the selected move unchanged; at +4 it changed both the value bin and the selected move. In the second position, +4 changed the value bin without changing the selected move. That is the cleanest current example of two frozen heads reading the same altered latent state differently.

Current reading

The orthogonal temporal component is tiny in norm, but it is not behaving like a generic direction. In this three-position smoke test it is consistently high-ranked for value-head sensitivity and moderately high-ranked at the shared association layer. The policy head is less special. This justifies a larger held-out position test; it does not yet establish chess-strength improvement or a general biological mechanism.

Numerical caveat found by the run

Some matched-control Jensen–Shannon means were emitted as NaN because a float32 subnormal probability underflowed again when halved inside the JS calculation. The pre-softmax metrics and percentile results above are finite. A stable log-space JS implementation is being pinned before the next run, so JS is not used as a headline result on this page.

The gate

r⊥ = r − ((r · h) / (h · h + ε)) h

Each shuffled control is permuted, re-orthogonalized against h, and rescaled to ||r⊥||. Every real/control direction is evaluated at both +λ and −λ; the larger effect is retained, preventing sign cherry-picking.
